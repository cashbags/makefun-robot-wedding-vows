**One-Line Robot Wedding Vows** — one line of wedding vows for a robot couple:

> I take you to be my wife, to have and to hold, from this day forward, until one of us is discontinued.

## The vow

The setup is the literal traditional wedding vow; the twist is the
ending — "until one of us is discontinued" replaces "till death do us
part" with a product-lifecycle ending, the one ending a machine actually
has. One real wedding promise, twisted once, deadpan, with no second
sentence to explain it. 102 Unicode code points, one line.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
# writes out/entry.txt — byte-identical on every run
```

`main.ts` (Node 22, stdlib only) holds the vow as one constant, checks it
against the competition's own gate first — 1–160 Unicode code points,
a single line, not only whitespace — and writes it to
`/output/entry.txt`. No clock, no random source, no network, so two runs
write identical bytes.
